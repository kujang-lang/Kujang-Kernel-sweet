# Kujang Kernel Sweet

**Android 16 · Stable · Efficiency · Daily**

Kujang Kernel Sweet is a custom Android kernel built for daily use.  
Focus on **stability**, **power efficiency**, and a smooth everyday experience on Android 16.

---

## Features

- Optimized for **Android 16**
- Prioritizes **stability** for daily driving
- Power **efficiency** focused tuning
- Smooth and responsive under normal workloads
- Clean and maintainable codebase

---

## Requirements

- Device running **Android 16**
- Compatible boot image / recovery for flashing
- Unlocked bootloader
- Basic knowledge of flashing custom kernels

---

## Installation

1. Download the latest release from the [Releases](../../releases) page.
2. Boot into recovery (TWRP / OrangeFox / official recovery that supports kernel flashing).
3. Flash the kernel zip.
4. (Optional) Wipe cache / dalvik.
5. Reboot to system.

> **Warning:** Flashing a custom kernel can brick your device if done incorrectly.  
> Always make a full backup before proceeding. Flash at your own risk.
